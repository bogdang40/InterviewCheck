# Public home page (`/`, signed-out visitors of a hosted deployment)

Scope and mode: Persuade. Shown at `/` when the deployment uses accounts and the visitor is not signed in; signed-in operators and the local edition get the workspace Overview. Audience: prospective customers and colleagues the owner sends the link to, plus the operator on the way to Sign in. Actions: Sign in (`/account/`) and Try the sample (`/sample/`, works signed out). Proof: the fictional sample exchange from `lib/sample.ts`, labelled as fictional. No customers, prices, accuracy figures or testimonials exist.

## Direction contract

THESIS: The page is the interviewer's review file for one answer: the candidate's words, the source they share, the count, the follow-up, the outcome. It refuses the category's split hero with a screenshot and a row of feature cards.

OWN-WORLD: The app's own studio: near-black #141617 ground, charcoal file panels with hairline borders, peach #ffba94 only for shared words, the count and the primary action. Instrument Serif italic for the headline and the file's finding, DM Sans for prose, IBM Plex Mono for file labels, tab names and numbers. Shared words marked as peach underlay, exactly as the workspace marks them.

STORY: In one viewport the visitor sees an answer that shares 19 words with an AI answer, and understands the tool shows evidence and suggests a follow-up, not a verdict. Scrolling turns the file's tabs (Policy, Answer, Sources, Follow-up, Outcome, Report). They sign in or open the sample.

FIRST VIEWPORT: Top bar: name and waveform mark left, Sign in right. Left column (5/12): headline in serif italic at display size, one sentence of subcopy, Sign in (peach) and Try the sample. Right column (6/12): the open file at full height of the viewport: tab strip in mono, the question, the candidate's answer with the shared passage marked, the source excerpt beneath it, a finding line with the shared-word count in large mono digits, and the suggested follow-up. Labelled "Fictional example".

FORM: Review file, my third-ranked structure of seven; seed key 3d895702. Signature interaction: when the file enters view, the shared passage is marked word by word and the count ticks up digit by digit (nixie raise), reduced-motion shows the final state.
